# Bueno English Club 🍫

Курс английского A1 для Никиты, Насти, Серёжи и Ани (и шпица Полины). Сайт статический: только HTML, CSS и JavaScript, без сборки и без сервера.

## Что внутри

Основу курса составляют 24 урока в 6 модулях, одинаковые для всех. Каждый урок работает в двух форматах:

- «Сам, 40 минут» — основной формат для самостоятельных занятий.
- «Вместе, 90 минут» — для офлайн-встреч.

Остальное:

- **Встречи офлайн.** После каждого модуля есть готовый сценарий примерно на два часа: разминка, повторение, игры, сценки про работу.
- **Бонус «Наша работа».** 24 дополнительных урока про работу каждого из нас, тоже одинаковые для всех. Проходятся по желанию. На встречах сценку ведёт тот, чья это работа.
- **Тренажёр речи.** Можно повторять за диктором или играть роль в диалоге. Озвучка работает через встроенный синтез речи браузера.
- **Карточки** со всеми словами курса.
- **Прогресс.** Хранится в браузере (localStorage), отдельно для каждого из четверых. Прогресс с разных телефонов не синхронизируется, поэтому для обмена есть кнопка «Скопировать отчёт для чата».
- **Работа без интернета.** После первого открытия сайт работает офлайн, например на даче. Его можно добавить на главный экран телефона как приложение.

## Как опубликовать на GitHub Pages

1. Создайте репозиторий, например `bueno-english`, и загрузите в него все файлы из этой папки, сохранив структуру.
2. Откройте Settings → Pages. В Source выберите Deploy from a branch, ветку `main` и папку `/ (root)`, затем нажмите Save.
3. Через минуту-две сайт появится по адресу `https://<ваш-логин>.github.io/bueno-english/`.

Для красивого превью ссылки в Telegram замените в `index.html` значение `og:image` на полный адрес: `https://<ваш-логин>.github.io/bueno-english/og-image.png`.

Все пути в проекте относительные, поэтому сайт работает и в корне домена, и в подпапке репозитория.

## Как править уроки

| Файл | Что в нём |
|---|---|
| `data/lessons.js` | 24 основных урока и задания «Говорю вслух». Формат описан в комментарии в начале файла. |
| `data/bonus.js` | Бонусные уроки про работу |
| `js/app.js` | Логика сайта |
| `css/style.css` | Оформление |
| `sw.js` | Офлайн-режим |

В упражнениях первый вариант ответа считается верным: на экране варианты перемешиваются. В заданиях с пропуском `___` допустимые ответы перечисляются через `|`, например `"is|'s"`.

## Приватность

Сайт на GitHub Pages открыт всем, у кого есть ссылка. В уроках упоминаются ваши имена, города и работа. Если это смущает, замените детали в `data/lessons.js` и `data/bonus.js`.

## Локальный запуск

```bash
python3 -m http.server 8000
# затем откройте http://localhost:8000
```
